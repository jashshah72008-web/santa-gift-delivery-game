# Santa Gift Delivery Game

A 2D snow-falling Santa gift-delivery game and physics simulation built in Python using **Pygame**.

## Features
- Real-time snowfall and gift-drop physics
- Interactive controls and collision detection
- Smooth 2D rendering built for Python / Jupyter environments

## Tech Stack
- Python 3
- Pygame
