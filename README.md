# 🎅 Santa's Gift Delivery Game

A festive 2D arcade game built with Python and Pygame. Fly Santa's sleigh across a snowy night sky, time your drops, and deliver gifts to the houses below to rack up points.

## ✨ Features

* **Smooth Sleigh Controls:** Glide Santa's sleigh across the screen to line up your shots.
* **Falling Snow Physics:** Dynamic snowfall animation for a winter atmosphere.
* **Gift Drop Mechanics:** Drop presents with realistic gravity physics.
* **Collision & Scoring System:** Earn points every time a gift lands on a house below.

## 🎮 Controls

| Key | Action |
| :--- | :--- |
| **Left / Right Arrow** (or **A / D**) | Move Santa's sleigh |
| **Spacebar** | Drop a gift |
| **Esc** / **Close Window** | Quit the game |

*(Note: Adjust the movement keys above if your current script uses automatic sleigh movement or different keybindings.)*

## 🛠️ Prerequisites

* Python 3.8 or higher
* `pygame` library
